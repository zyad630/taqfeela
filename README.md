# ☕ نظام إدارة ونقطة بيع الكافيه الاحترافي (Cafe POS System Pro)

نظام تجاري متكامل ومخصص لإدارة الكافيهات والمطاعم وقاعات البلايستيشن، يعمل **بدون إنترنت تماماً (Offline 100%)** كتطبيق سطح مكتب فائق الأمان والسرعة.

---

## 🚀 طرق تشغيل البرنامج:

### الطريقة الأولى (التشغيل السريع):
* اضغط دبل كليك على ملف **`تشغيل_البرنامج.bat`** الموجود داخل المجلد الرئيسي، وسيتم تشغيل النظام مباشرة على سطح المكتب.

### الطريقة الثانية (عبر موجه الأوامر / التطوير):
```bash
npm run electron:dev
```

---

## 🔐 سياسة الدخول والأمان:

> ⚠️ **ملاحظة أمنية هامة:**
> يتم تسليم بيانات الدخول الأولية بشكل مستقل عند التثبيت، ويفرض النظام تلقائياً تغيير كلمة المرور الافتراضية عند أول تسجيل دخول لضمان حماية بيانات المنشأة. جميع كلمات المرور مشفرة بخوارزمية **bcrypt** مع حماية ضد محاولات التخمين (Rate Limiting & Lockout).

---

## 🌟 الميزات والمواصفات التجارية للنظام:

1. **أمان وحماية كاملة (Production Hardening):**
   - حماية خادم الواجهة الخلفية (Main Process Authorization) لجميع العمليات الحساسة (حذف الفواتير، تعديل الأسعار، إدارة الموظفين والرواتب، الإعدادات).
   - إغلاق أدوات المطورين (DevTools) وشريط القوائم تلقائياً في بيئة الإنتاج لمنع أي تلاعب.
   - تشفير كلمات المرور باستخدام **bcryptjs**.

2. **سلامة وتماسك البيانات (Data Integrity & Transactions):**
   - حفظ ذري آمن لقاعدة البيانات (Atomic Save مع Debounce) يمنع تلف البيانات في حال انقطاع التيار الكهربائي المفاجئ.
   - عمليات مالية محمية بالمعاملات المركبة (SQL Transactions) لكل عمليات البيع وسداد النوتة والشيفتات.
   - منع البيع بدون فتح شيفت نشط لضمان دقة الحسابات.
   - تسلسل ترقيم الفواتير الموحد والمتصاعد المستقل عن مسح الفواتير.

3. **إدارة الورديات وجرد الخزينة (3 شيفتات / 24 ساعة):**
   - فتح الشيفت بعهدة نقدية أولية.
   - تسجيل فوري للمصروفات النثرية ومشتريات الخامات مع تحديد الفئة.
   - إغلاق الشيفت مع جرد ومطابقة النقدية وتوضيح أي عجز أو زيادة.
   - عزل فواتير الكاشير بحيث لا يرى إلا فواتير شيفته الحالي، مع إتاحة السجل الكامل للمدير.

4. **دفتر النوتة والآجل (Customer Debts):**
   - تسجيل الفواتير الآجلة باسم العميل ورقم هاتفه مع سداد فوري جزئي أو كلي.
   - سداد ديون النوتة بطريقة FIFO وربط المبالغ المسددة بالخزينة والشيفت النشط.
   - حظر حذف أي حساب نوتة بدون إدخال كلمة مرور المدير العام.

5. **كشف الرواتب وحسابات الموظفين (Payroll & Attendance):**
   - احتساب الرواتب الشهرية وصافي المستحق بعد خصم أيام الغياب والجزاءات وإضافة المكافآت.
   - سجل حضور وجرد مبيعات كل كاشير وموظف لكل شيفت ولكل فترة.

6. **النسخ الاحتياطي التلقائي واليدوي (Backups & Restores):**
   - إنشاء نسخ احتياطية تلقائية مع إغلاق كل شيفت وتدوير النسخ وحذف القديم تلقائياً.
   - إمكانية حفظ نسخة احتياطية يدوية وتحديد مسار الحفظ أو استرجاعها مباشرة من واجهة الإعدادات.

7. **تصدير التقارير إلى Excel / CSV:**
   - تصدير سجل الفواتير والمبيعات.
   - تصدير كشوف الرواتب الشهرية.
   - تصدير تقارير المبيعات اليومية والشيفتات بترميز UTF-8 المتوافق مع برامج Excel العربية.

8. **نظام الترخيص غير المتصل (Offline Hardware-Locked Licensing):**
   - حماية وتوليد ترخيص مقفل على عتاد الجهاز (Machine ID).
   - تفعيل فوري بدون الحاجة للاتصال بالإنترنت.

9. **الطباعة الحرارية والصامتة (Silent Thermal Printing):**
   - دعم الطباعة المباشرة الصامتة لطابعات الفواتير والكاشير (80mm / 58mm).
   - إمكانية تحديد اسم الطابعة الافتراضية من الإعدادات.
